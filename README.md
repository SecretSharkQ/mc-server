# Сайт-кнопка для сервера qwerty123 (FreeMcServer)

Мобильная страница с большими кнопками: подруга открывает ссылку, жмёт
«ЗАПУСТИТЬ» — сервер стартует. Логин и пароль никому не нужен.

- Страница сервера: https://freemcserver.net/server/2219537
- Запуск: https://freemcserver.net/server/2219537/start
- Продление: https://freemcserver.net/server/2219537/renew
- IP: `qwerty.enderman.cloud:26783`

Проверено вживую: запуск и продление с этой страницы работают без логина,
сервер поднимается за пару минут.

## Про капчу (важно, но не страшно)

На сайте FreeMcServer две проверки, и обе не мешают людям:

1. **Cloudflare при входе** («Just a moment...») — мелькает иногда при открытии
   ссылки и проходит сама за 5–30 секунд (иногда нужно тапнуть одну галочку).
2. **Невидимая капча Turnstile внутри кнопок** — для живого человека в обычном
   браузере срабатывает автоматически, нажимать ничего не надо.

Эти проверки существуют против ботов, поэтому автоматизировать кнопки
простым скриптом (curl / GitHub Actions) нельзя — их запросы капча не пропустит.
Людям с телефона всё работает.

## Как залить на GitHub Pages (без git, через браузер)

1. На [github.com](https://github.com) → **New repository** → имя например `mc-server` → Public → Create.
2. На странице репозитория: ссылка **«uploading an existing file»** → перетащи `index.html` → **Commit changes**.
3. **Settings → Pages →** Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
4. Через минуту сайт: `https://ТВОЙ_ЛОГИН.github.io/mc-server/`.
5. Скинь подруге эту ссылку — пусть сохранит на рабочий стол телефона.

Можно и без GitHub: просто скинь подруге ссылку
`https://freemcserver.net/server/2219537` — на ней те же кнопки
«Start Server» и «Renew Server».

## Как работает бесплатный сервер на FreeMcServer

- Продление нужно **каждые 4 часа** (6 ч — с рекламой), иначе сервер выключается.
- Если после запуска **никто не зашёл**, сервер гаснет через **30 минут** (60 — с рекламой).
- Пока игроки онлайн — сервер живёт до конца 4-часового таймера, потом жми «Renew».
- Ничего не удаляется: выключенный сервер можно запустить в любой момент;
  полное удаление — только после 30 дней без продлений.
- Справка: [How Server Renewal & Expiration Work](https://blog.freemcserver.net/faq/how-server-renewal-expiration-work),
  [Public Page](https://blog.freemcserver.net/faq/what-is-the-public-page-and-how-do-i-use-it).

## Авто-продление

Простой скрипт не сработает из-за капчи (см. выше). Рабочие варианты:

- **Подруга/ты с телефона**: открыть страницу (или твой сайт) → «ПРОДЛИТЬ» →
  «Renew Server!». 10 секунд.
- **ZCode-автоматизация**: пока включён твой комп и запущен ZCode, она сама
  открывает страницу продления и жмёт кнопку каждые 3 часа. Управление — на
  вкладке Automations в ZCode.
